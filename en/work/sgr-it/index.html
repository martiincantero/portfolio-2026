01 / THE IDEA, AT A GLANCE

Context

Rooms, laptops, projectors and tablets share a challenge: their availability depends on time. SGR-IT organizes inventory, bookings and administration in a web application with two roles.

04 / Technical judgement

Technical judgement

01

Do not trust the interface alone.

The AJAX check guides the user, but createReserva checks availability again and validates date order before insertion. The schema also contains triggers that check for overlapping bookings.

02

Separate identity from permission.

Authentication functions check the session and the role. Cancelling a booking checks whether the person acting owns it or has administrator permissions.

03

Make the rules visible.

The model connects users, resources and bookings. Booking queries use bound parameters, and password verification uses password_verify. These are specific mechanisms, not a blanket security guarantee.
