MC / Privacidad

Privacidad, sin letra pequeña.

Este portfolio no incorpora analítica, píxeles publicitarios ni formularios que envíen datos a un servidor propio.

Preferencia de idioma

Al elegir español o inglés, se guarda esa elección en el almacenamiento local de tu navegador (mc-language). Solo se utiliza para recordar el idioma en tu próxima visita. Puedes borrarla desde los ajustes de tu navegador.

Preferencia de movimiento

Puedes reducir el movimiento desde el pie de página. Esa preferencia se guarda localmente (mc-motion). La preferencia de accesibilidad de tu sistema se respeta siempre. No se envía a ningún servidor.

Correo y enlaces externos

El enlace de contacto abre tu aplicación de correo. El botón de copiar email utiliza el portapapeles solo cuando lo pulsas. GitHub y LinkedIn son servicios externos con sus propias políticas de privacidad.

Alojamiento

El proveedor de alojamiento puede tratar datos técnicos de la petición, como la dirección IP, para servir y proteger la web. La configuración inicial está preparada para GitHub Pages. Esta descripción deberá revisarse si se añaden servicios o se cambia el alojamiento.

Ejemplos interactivos

La simulación de disponibilidad se ejecuta dentro de tu navegador. No guarda horarios, no envía datos y no crea reservas.

Contacto

Para cualquier cuestión relacionada con este sitio, puedes escribir a martincantero.it@hotmail.com.
